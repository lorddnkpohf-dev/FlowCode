# Contributing

FlowCode is proprietary. The source code is not open source and is not distributed under an open-source license.

Only the prebuilt installer is published for end users. The public repository contains documentation, design assets, and templates — not buildable source.

You may contribute to:

- Documentation (README, guides, translations).
- Visual design (mockups, screenshots, logo variations).
- Repository templates (issues, pull requests, security policy).

Do not submit source code, build scripts that reveal internal logic, or anything that implies the project is open source.

Design rules:

- Monochrome palette matching the logo. No gradients, no rainbow accents.
- Icons from Icons8, each used once.
- Minimal, iPhone-like style.

For bugs or feature requests, open an issue. For security reports, see SECURITY.md.
